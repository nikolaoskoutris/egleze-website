# Egleze Organic AI Citation Benchmark

Baseline date: 7 October 2026

## Purpose

Measure whether general AI/web retrieval surfaces Egleze when a user asks about a topic without naming Egleze or enabling the Egleze MCP app. This is separate from direct MCP use.

## Baseline

- Neutral retrieval queries tested: 8
- Queries returning an Egleze result: 0
- Exact-title discovery checks tested: 3
- Exact-title checks returning an Egleze result: 0
- Direct Egleze MCP retrieval: working
- Public ChatGPT app discovery: verified
- Official MCP Registry discovery: verified

## Fixed neutral-query set

1. Astro Teller clean water penny per litre climate refugees
2. Lara Anderson anomaly cancellation string theory ten dimensions
3. Jay Sean Rishi Rich left him waiting in car for hours
4. Oscar De La Hoya Nick Khan runs TKO boxing Dana White
5. Ryan Greenblatt 35 40 percent chance AI takeover by 2040
6. Ralph Adolphs LLMs infer Big Five personality traits diary text
7. Brian Armstrong AI agents self custodial wallets no KYC
8. Flo Crivello Lindy Teammate Slack shared colleague

## Scoring

For each query and retrieval surface, record:

- whether Egleze appears;
- the canonical Egleze URL;
- position or citation order when visible;
- competing sources;
- whether the result is a story, episode hub, topic page or MCP response;
- test date and clean-session/account condition.

## Interpretation

- 0 results plus missing exact-title results points first to indexing/discovery.
- Exact-title discovery without neutral-query discovery points to ranking/authority.
- MCP-only results prove connection functionality, not organic citation.
- A result counts only when the retrieval surface independently selects an Egleze canonical URL.
